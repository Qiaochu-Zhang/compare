# V33：via 质量控制与物理尺寸提示

V33 基于 V32 的独立脚本，保留其 V27 定位、Yakun 原灰度边缘验证、有限补检、四排 slot 完整列和 300 秒独立进程时限。内部 `_v32_*` 等名称表示继承流程，不需要运行或导入旧版脚本。

## 参数与数据流

`V33DetectionOptions` 统一验证参数：尺寸为有限正数，圆形度为 0–1，同图尺寸偏差为 `[0, 1)`（0 关闭），尺寸容差为 `(0, 1)`。CLI 接收 `slit` 及 `slot` 的同义参数名。

`main_v33(..., detection_options=...)` 接受该对象或字典，将其序列化到每张图的 worker 请求。worker 在可恢复的上下文中应用参数，BEFORE 的 auto 两次模型尝试共享相同配置及单图预算。尺寸按各图 `PixelSize` 独立换算，图像处理失败时恢复上下文；不把上一张图的比例尺或参数遗留到下一张图。超出图像物理范围的尺寸提示明确报错。

## via：只在最终原图轮廓上应用用户阈值

1. 定位及原图轮廓细化沿用 V32。前期固定圆形度门槛不会比用户阈值更严格；最终仍须通过原图信号、solidity、长宽比、阵列及边界检查。
2. 对最终浮点轮廓重新计算 `C = 4πA/P²`，`C < via_min_circularity` 时剔除。默认 0.75；调整该参数只影响 via。补检等级不会覆盖该阈值。
3. 计算等效直径 `D = 2√(A/π) × PixelSize`。若填入预计直径，则检查 `D` 是否位于预计值的 `1 ± size_tolerance` 范围内。
4. 从通过上述检查的同图对象计算一次中位直径 `M`，若至少有 3 个孔且启用尺寸偏差筛选，则剔除 `|D/M−1| > via_max_size_deviation` 的对象。默认 0.30，不做反复中位数裁剪。对象不足时记录跳过。同图参考不会来自另一张图或另一阶段。
5. 重新拟合保留对象的坐标轴，沿用 V32 的跨度验证，重新分配 object ID。标注、CSV、Excel 和后续统计都消费保留后的同一组对象。剔除对象及阈值写入 `rejected_objects.csv`。

默认设置是通用起点，并非真实 SEM 数据标定结果。像素分辨率和轮廓噪声会影响圆形度；提高阈值会减少保留孔数。原来的其他形状条件仍有效，降低圆形度阈值不保证所有非圆形物体都能通过。

## 尺寸提示真正参与定位

- **via 直径**：优先作为像素搜索尺度；匹配模板在容差内取多个尺度，候选不足时仍能使用用户尺度。未填时继续使用图内候选中位直径 / 标称回退机制。最终 CD 来自轮廓，与输入直径独立。
- **slit 宽度 / 长度**：新增尺寸辅助候选生成。宽度控制横向去背景形态学窗口、候选宽度范围及缺失格点候选评分，长度辅助纵向平滑。候选来自实际图像掩膜，不直接生成测量矩形。候选合并到原有四排定位，再用原图轮廓法复核；最终仅统计完整列的最下排。长度范围只用于最下排，避免删除真实长度不同的其他三排。
- **trench 宽度**：控制垂直暗条背景尺度、横向峰抑制距离及局部边缘搜索窗口，搜索受邻条间隔限制。
- **trench 间隙**：在上下端点搜索区域中寻找方向相反、对比度足够的真实灰度跃迁，选择间距在容差内的端点对；随后仍执行原图宽度/端点验证。
- 只对填入的维度检查最终尺寸范围；所有原图证据门槛继续生效。容差不是测量误差估计，也不把实测值吸附到输入值。

尺寸提示在一次运行中对所有条件及两阶段生效。如果希望允许较大的真实前后变化，应相应放宽容差、调整或省略该项提示。slit/slot 在结果表中继续使用 `slot`，保持现有下游格式。

## 输出与可追溯性

`settings.json` 保存 `detection_options`、圆形度定义、同图参考规则和 slit 长度作用范围。对象与拒绝记录中的 `input_*` 保存所用参数；有效 via 还记录等效直径、中位直径、参考数量、相对偏差以及是否应用尺寸筛选。图像状态包含筛选数量及补检信息。

实际运行入口为 `main_v33`，工作簿名为 `SEM_0830_0831_before_after_V33_results.xlsx`；历史兼容列如 `selected_v25_pattern_key` 保留。

## 验证与限制

`tests/test_v33.py` 对 V33 执行继承的原图边缘精度、四排约束、物理尺度、单图超时及批处理继续运行测试。`tests/test_v33_controls.py` 验证新增用户参数及实际处理流程。

新增合成验证包括：

- 20 个孔中包含 1 个直径 56 px 的异常孔、其余 19 个直径 40 px：关闭尺寸筛选时保留 20 个；最大偏差 0.20 时保留 19 个，剔除原因和统计数量一致。
- 低对比、带背景梯度的 slit 图额外施加 3.5 px 高斯模糊：无尺寸提示时无完整有效列，提供 17 × 21 nm 的最下排尺寸后恢复 2 列；仍需四排及至少 85% 原图边缘支持。
- 输入预计直径 90 nm 的 via 图，真实直径 80 nm：独立 worker 输出约 80 nm，且记录预计值为 90 nm，不把结果强制设成提示值。
- 输入 trench 预计宽度 44 nm、间隙 130 nm，实际 40/120 nm：检测仍按原灰度边缘测得接近真实值。
- via 圆形度设 1 时，常规及两级补检均不能绕过阈值；设置 via 阈值不影响 slit/trench。
- 提供完整尺寸提示的空白图仍无有效对象。

目前没有本批真实 SEM 图像及比例尺文件，因此以上是合成图与程序流程验证。严重模糊可能无法提供可靠边缘，尺寸提示不保证恢复全部对象；圆形度和尺寸范围也可能排除真实形变，使用时应结合剔除日志和标注复核。

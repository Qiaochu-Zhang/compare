# V40：低对比度孔槽的亮边定位与内侧测量

V40 基于 V39 建立独立四文件版本。内部与背景灰度相近时，仍可能有明亮的孔槽外沿；本版以原图亮圈作为 slit / via 的独立证据，在首轮即参与定位，也补充已经部分成功的图片。trench 沿用原有条体与端点算法。

## 1. 亮圈候选

`_v40_bright_rim_candidates` 始终读取 `_v32_raw_gray` 对应的原始测量灰度，不使用增强图进行最终测量。亮圈为绝对明亮信号，不跟随传统 `FEATURE_POLARITY` 翻转。

1. sigma=0.65 平滑，原图与平滑差的 MAD 估计噪声，下限 0.15。局部响应下限为 `max(2.5,4×noise)`。
2. 对 5、9、17、33、65 px 椭圆核做 top-hat，提取局部亮细线并减弱慢变背景。只使用图像容得下的尺度；这些是亮边厚度搜索尺度，不是预计孔径。
3. 在高于噪声下限的正响应中估计 85 分位峰值，依次按 40%、25%、60% 峰值阈值定位，且阈值不低于响应下限。
4. 3×3 闭运算只连接微小断点。用 `RETR_CCOMP` 的子轮廓寻找亮圈包围的内部；实心亮斑自身没有此内部孔洞。闭合掩膜不能直接产生测量。
5. 定位面积 20 px² 至整图 10%，最小跨度 4 px、solidity 至少 0.65，须有图像边界留白。多尺度/阈值按位置去重，允许明显不同内沿种子重试。
6. 立即执行下节的原图亮峰审核；slit 继续通过原形状检查，via 通过原椭圆归一化形貌检查。最多审核 240 个种子、保留 120 个定位候选；每次阈值最多查看面积最大的 120 个孔洞。

亮圈连通时可能产生小型间隙孔洞；其候选身份不代表测量，后续搜索尺度、实际格位、形貌和最终审核仍必须成立。

## 2. 原图内侧边缘

`_v40_supported_rim_contour` 沿实际种子轮廓等弧长采样 48–240 个点，计算向外法线，使用原始灰度追踪；不拟合矩形或椭圆来替代轮廓。

- 对局部原图的外侧背景做稳健平面去倾斜，沿法线每 0.5 px 采样，并在切向 −0.5、0、0.5 px 平均。传统 bright 极性的符号变化在此撤销，保留原图亮峰的方向。
- 内侧采样距离 `clip(0.35×较小跨度,3,10)` px，外侧距离 `clip(0.75×较小跨度+6,10,32)` px；交点相对种子的位移限于 `clip(0.20×较小跨度,2,5)` px。
- 每条法线必须观测到内部低平台 → 上升 → 亮峰 → 外侧回落；峰值须比内、外两侧参考都高至少 `max(4,5×局部噪声)` 灰度。只有单侧明暗交界不会通过该规则。
- 在内部参考与该亮峰之间取 50% 灰度交点，只选择朝向内部的上升沿。峰值中心、外侧下降沿和光晕宽度不作为孔槽尺寸。
- 沿闭合轮廓用继承的动态追踪选连续路径。有效法线至少 85%，最长连续缺边不超过 8%；小缺口只在实测端点之间线性连接，不保留未被支持的种子尖端。
- 细化后面积为种子的 0.65–1.5 倍，两个跨度各为 0.70–1.35 倍，中心偏移不超过 `max(2 px,0.12×较小跨度)`。不满足时拒绝，不把种子直接作为测量。

最终 `_v32_refine_desc` 对标记为亮圈来源的候选使用此路径，其余候选继续走 V38 完整性/原图灰度路径。增强图、尺寸提示或预先有效的候选遇到空白原图仍不能通过审核。

此版本明确采用“亮边内侧半高交点”口径。极细、离焦或不对称发光的亮边会改变交点位置；亮边对应的物理工艺边界需要真实 SEM 和参照尺寸标定，合成图不能证明绝对 CD 准确度。

## 3. slit 融合与阵列约束

- 首轮将已审核亮圈内沿与常规候选融合，同位置优先使用通过原图亮峰审核的内沿；多阈值不重复计数。原有 V35 首轮和 V37 补充路径继续处理普通暗槽/弱槽。
- 补充未被首轮接纳的亮圈时，使用实际观测行级。四排必须实际出现；缺第四排不能提升第三排，缺失轮廓不画出、不填零。
- 至少七个亮圈、四排各有真实对象且其中至少三排有两个对象时，尝试从这些亮圈估计实际列距和横向相位。至少 85% 亮圈须符合该相位，才启用独立的亮圈阵列约束。
- 启用后，其他已测量候选也须接近这些实际行级与列位，轮廓不能跨过 ±0.49 格距边界。冲突对象记为 `slot_outside_bright_rim_grid` 并剔除，不将它移动或裁剪进格位。该检查用于避免弯曲背景上的大块伪候选借用真实亮圈的四排支撑。
- 最终沿用完整列/部分列审核：完整四排一列可独立保留；部分列要求四排都有实际观测、至少两列且三排有重复支撑，每个测量列包含最下排和 `slit_min_column_rows` 指定行数。
- 只测量最下排，X/Y 沿实际阵列轴投影，乘每图 PixelSize 得到 nm。显式 slit 宽度/长度和各自容差继续作用于最终尺寸，长度提示不筛掉其他排的不同长度。

## 4. via 融合

- 亮圈内沿加入整体观测轮廓路径，在同位置与传统候选去重；继续保留径向定位与普通整体轮廓的互补。
- 显式孔径提示优先，其次保留可靠首轮尺度；首轮没有可靠尺度时可由重复亮圈内沿估计。默认不新增同图尺寸硬筛选。
- 内沿通过原图追踪后，执行既有形貌：solidity ≥0.85、凸性 ≥0.88、椭圆归一化残差 P95 ≤0.18、粗糙度 P95 ≤0.06、最小跨度 4 px。椭圆仅用于审核，原图轮廓仍是尺寸来源。
- 继续执行二维阵列、邻位半格边界、最终投影跨度、显式圆形度/预计直径和可选同图尺寸偏差筛选，并按实际格位/最终轮廓去重。
- 四个亮圈与普通四孔一样，只在继承的 V39 零结果试验中允许完整 2×2 启动：80°–100°、四格唯一、中心残差 ≤min(2.5 px,0.08×间距)，且四孔全部通过最终审核。三孔、单排或最终筛掉一孔仍拒测。

## 5. 继承流程、输出与审计

原正常流程及 L1/L2 为零时，继续执行继承的 V39 原极性多尺度 L3、相反极性 L4；已有结果不会进入这些零结果试验。亮圈定位在每次 slit/via 主测量中独立可用，低于四个普通候选时也允许用原图有效亮圈进入 L3/L4 主测量。

single / compare、数字子目录、自然排序 trench/slot/via、Region 从 2 开始、同名 TXT 的 PixelSize、六项 nm 尺寸、对象加权统计、均值 ± 样本 SD 和 n=1 的空 SD 均保留。所有尝试含 auto 两模型继续共享单图最多 300 秒硬时限。

- 入口：`sem_before_after_compare_0831_V40.py`、`main_v40`、`V40DetectionOptions`。
- `script_version=2026-10-16-V40-BRIGHT-RIM`，`source_algorithm=V40_bright_rim_on_V39_recovery`；默认目录/工作簿带 V40。
- 对象：`v40_bright_rim_used`、`v40_rim_prominence_gray`、`v40_rim_peak_offset_px`、`v40_rim_boundary_definition`、`v40_rim_polarity=bright`，继续带 `edge_*` 原图证据。peak offset 不是完整亮边厚度。
- 亮边对象的 `edge_method=V40_bright_rim_inner_gray50_normal_tracking`，`slit_locator_path` / `via_locator_path=V40_bright_rim`；对应 boundary rule 为 `V40_original_bright_rim_inner_slope`。
- 亮边测量的两个置信字段均为 `BRIGHT_RIM_REVIEW`，优先于零结果复核文案；`v39_zero_recovery_*` 与 `auto_fallback_*` 继续准确记录是否经过零结果恢复。
- image_status：`v40_bright_rim_measured_count` 是最终亮边测量数；`measure_v40_rim_*` 为候选/审核数，slit 另记录亮圈接纳、补入、阵列锁定/冲突数，via 另记录亮边测量数。候选数不等于结果数。
- settings：`v40_bright_rim_enabled/rule/limits/review_flag`；历史 V35/V37/V38/V39 函数与字段保留其来源含义。
- 标注始终显示原始 SEM，绿色最下排 slit / 有效 via 与统计对象一致。发生零结果恢复时横幅带 V40，方法名称仍保留 V39 来源。

## 6. 验证与限制

`test_v40_bright_rim.py` 直接加载 V40，覆盖内部/背景同色、细弱亮边、不同亮晕厚度、双向坡度、内侧尺寸、原图空白、噪声/斜坡/实心亮斑、宽断口、混合孔槽、缺失上下排、显式参数、平滑椭圆/异常形貌、严格四孔、强纹理伪候选，以及真实单图、single/auto worker 和导出。

`test_v40_recovery.py` 和 `test_v40_workflows.py` 将既有零结果恢复、弯曲/密集/弱/椭圆对象、部分 slit、两模式、真实 CLI、统计/Excel/作图和硬超时测试实际用于 V40。完整回归结果及 ZIP 校验见 `md/2026-10-16_V40_bright-rim.md`。

最终全仓库 **336 项测试全部通过，1248.800 秒，其中 48 项直接验证 V40**；包含最终尺度来源审计、实际 CLI/worker 和超时验证。

受控的细弱亮边 slit，V39 首轮为 0，V40 首轮为 3 个最下排；同色内部/背景的亮圈场景可定位 12 个 slit、测量 3 个最下排，或测量 20 个 via。所有计数只描述合成场景。

没有本批真实 SEM 原图/TXT，尚不能量化实际召回率、误检率或工艺尺寸误差。大范围开口、亮边太粗/太窄/模糊、极弱或饱和且粘连的亮圈、无背景留白、错误输入顺序/尺寸提示、缺整排 slit 或支撑不足仍可能无结果。仅 Linux/Python 3.12 已运行，Windows/macOS 原生环境未验证。

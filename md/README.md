## 记录模板

版本任务文件名：`YYYY-MM-DD_V<N>_<简短主题>.md`。仓库级任务使用 `YYYY-MM-DD_repo_<简短主题>.md`。

```markdown
# 日期：修改主题

- 状态：进行中 / 已完成 / 验证受阻
- 基于版本：V<N>（目录）
- 目标版本：V<N>，或“仓库级修改，不升版”
- 目的：本次要解决的问题

## 具体改动

- 文件路径：修改内容及行为变化

## 验证

- 命令或检查方式：实际结果
- 未验证事项或已知问题：如实填写，没有则写“无”

## 交付

- ZIP：路径及完整性、内容一致性检查结果，或说明不适用
- GitHub 同步目标：仓库与分支；失败时记录原因
```

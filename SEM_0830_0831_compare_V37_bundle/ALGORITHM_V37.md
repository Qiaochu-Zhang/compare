# V37：完整外边缘复核与局部弱图案补检

V37 基于 V36，保留单文件夹/前后对比模式、六项尺寸指标、每图 PixelSize、均值 ± 样本 SD 作图、可选尺寸提示、via 非圆形貌审核、slit 局部缺失和每图 300 秒上限。独立脚本不依赖旧版本文件。

## 修复对象与复现证据

局部边缘支持并不能保证轮廓完整。旧 `_v32_supported_contour` 只在初始轮廓法线附近约 2–6 px 搜索，并偏好较小位移；“上深下浅”的同一对象内部也存在有方向的灰度跃迁，可能被当成外边缘。半轮廓附近的全部采样点都有跃迁时，局部支持率甚至为 100%，仍会测得错误长度。

使用相同上半轮廓种子和原图复现：真实 slit 为约 17×71 px，旧局部追踪得到约 17×35 px；真实 via 为约 45×77 px，旧结果约 44.8×33.1 px。V37 识别外侧仍有连续原图前景后，重新定位并追踪完整边缘，测回约 17×71 / 45×77 px。这里是边缘模块的受控合成复现，不表示已经验证真实 SEM 图片或旧版整条流水线在所有图片上的行为。

## 保留精细追踪，先检查轮廓是否完整

原局部追踪实现保留为 `_v32_supported_contour_legacy`。新的 `_v37_supported_contour` 包装它，`_v32_supported_contour` 和 `_v32_refine_desc` 统一接入新流程：

1. 先尝试原来的灰度 50% 法线追踪，记录支持率、连续缺边和几何变化。
2. 在初始对象周围建立原图局部窗口：padding=max(12,1.15×较大包围盒跨度)+8 px。额外 8 px 为恢复后的弱端点留出背景，避免窗口再次截断或把弱前景纳入背景估计。
3. 沿用稳健边缘背景平面拟合，计算局部原图前景响应及噪声。沿现有轮廓法线向外探测 max(4,0.30×较小跨度) px，记录尚未解释的外侧前景比例。
4. 原追踪成功且外侧前景比例不超过 0.12 时保留该结果，不无条件替换良好轮廓。
5. 否则，在原图窗口中使用噪声下限及多档强度阈值寻找连通区域。下限 max(1.5,3.5×噪声)，同时尝试下限的 1.5/2/3 倍和种子响应的 5/10/15/30/50%，覆盖强上半部与弱下半部。
6. 候选不能触碰窗口边缘；必须覆盖至少 60% 的原种子核心，定位面积处于原种子的 0.65–4.5 倍内。此范围允许修正半个对象的初始定位，但限制跳到邻近图案或无限扩张。
7. 对候选重新执行原始灰度精细追踪，仍要求至少 85% 支持、连续缺边约 8% 上限、原有面积/跨度/中心变化检查。面积变化检查相对于新的真实定位候选执行，而非强制把半轮廓局限在原错误位置附近。
8. 再检查外侧前景比例。可靠完整候选返回；若现有轮廓仍明显截断而无法重建，返回 `UNRESOLVED_OUTER_BOUNDARY`，不以旧截断轮廓统计。

区域掩膜只提供定位轮廓，最终测量仍来自原图的真实灰度边缘。没有对结果进行模板拉伸、拟合椭圆替代、把实际短图案延长或用预计尺寸填充。原图空白或仅有背景梯度时，即使定位图看起来有形状，也不能产生有效测量。

## 补检适用于部分成功的图片

旧版整图自动增强仅在有效对象为 0 时触发，容易漏掉“同图强对象已找到、弱对象仍缺失”的场景。V37 新增 `_v37_feature_candidates`，在每张 slit/via 图片上执行多尺度原图局部对比定位：

- 用与对象尺度相关的横向（slit）或二维（via）形态学背景响应，去除慢变亮度背景。
- 按噪声和局部对比生成多档候选，保留完整低阈值区域，避免把整个弱对象替换为深色核心。
- 候选保留面积、边界、最小可分辨跨度、形貌及数量上限；随后仍须经过真实边缘、阵列和最终形状审核。
- via 的候选补充在图内尺度估计前合并，最终按实际格位及细化后中心去重；slit 的补充在四排定位前合并，然后逐个复核边缘。

这项补检不会要求所有对象大小、亮度或 before/after 测量值相同。V36 的圆形度/同图偏差默认关闭，异常锯齿/多瓣审核保持，slit 缺失成员仍不补造。

## trench：局部条体包络与端点平台

新增 `_v37_trench_pairs`、`_v37_body_edges`、`_v37_transition`。通过运行时入口接入原有 trench 几何、坐标轴、平均上下宽度和标注输出：

1. 在原图的每一行独立估计横向背景，以多尺度局部对比响应定位上下条体；减少强上条或强邻条对弱对象的全局阈值压制。
2. 上下体区域的响应都必须存在；按噪声阈值找真实 X 峰，保留既有候选数上限，不凭阵列数量补峰。
3. 左/右侧壁从实际条体包络定位，再用两侧原灰度平台的局部 50% 交点细化。上下条各自测量，宽度仍取两者平均。
4. 在两条的共同内部 X 范围，观察纵向前景包络。短小空洞只用于定位时连接；最终顶/底端点必须分别有两侧真实灰度平台和有方向的 50% 交点。
5. 因而强内部亮度台阶不再仅凭梯度大就抢占真实端点，也不把全图中位端点直接复制给各列。垂直/水平剖面采用中位数减少局部污渍影响。
6. 两条均须有原图信号，端点顺序、用户间隙/宽度范围及坐标轴投影检查继续执行。只有一侧条体或无可信交点时拒测。

Trench 的既有大致上下区域和端点搜索范围仍保留，当前版本并非任意构图的通用线段识别器。局部端点灰度差需至少 max(2,3.5×剖面噪声)；微弱到无法分辨的末端不能保证恢复。

## 追溯字段与使用方式

`boundary_relocalized` 表示使用区域重定位路径，并非准确率标记。相关字段包括 `boundary_recovery_attempted`、`boundary_outer_contact_fraction`、`boundary_seed_outer_contact_fraction`、`boundary_search_roi_px`、`boundary_seed_area_ratio`、`boundary_region_threshold_gray`、`boundary_recovery_method`。无需重定位对象的部分字段为空。

image_status 统计 `measure_v37_boundary_relocalized_count`、`measure_v37_local_contrast_candidates` 及 `measure_v37_trench_*` 候选数、噪声、有效对数。拒绝日志中的 `edge_status=UNRESOLVED_OUTER_BOUNDARY` 表示外侧仍有未解释前景，新的尝试没有得到可靠完整轮廓。

settings 保存完整性规则、局部窗口/面积/核心重叠限制、局部候选及 trench 平台规则。入口升级 `main_v37`，工作簿为 `SEM_0830_0831_single_V37_results.xlsx` / `SEM_0830_0831_before_after_V37_results.xlsx`；命令与其余输出沿用 V36，运行须使用新输出目录。完整说明见 `README_V37.txt`。

## 验证与限制

`tests/test_v37_edges.py` 实际加载 V37，覆盖半轮廓截断复现及真实完整跨度、弱下半部与明亮极性、实际短图案不拉长、空白/倾斜背景拒测、异常边缘不替换成椭圆、同图弱对象检出、trench 明暗台阶/弱下条/交替弱条、比例尺及真子进程导出。

`tests/test_v37_morphology.py` 将 V36 的非圆形貌/污染缺失场景直接用于 V37；拒绝阶段可能提前到原图完整性检查，因此测试按“异常对象未进入测量 + 有拒绝证据”验证，不强制只能由某个后续形状阈值拒绝。`tests/test_v37_workflows.py` 直接验证新版本的两种模式、自然排序、统计/图表、导出、失败继续及超时。

完整回归 205 项全部通过，耗时 509.393 秒，其中 38 项直接验证 V37。ZIP 校验及本次实际限制见仓库 `md/2026-10-15_V37_full-boundary-recovery.md`。本批问题的真实 SEM 原图、TXT 和标注尚未提供，因此本版证据来自合成图和程序流程，不代表用户图片中的所有漏检已经修复。严重污染相连、未知构图、极低对比或大段真实边缘缺失仍可能拒测或需要结合原图调整。

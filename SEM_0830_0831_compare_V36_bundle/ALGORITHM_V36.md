# V36：边缘优先的非圆 via 与允许局部缺失的 slit 阵列

V36 从 V35 独立脚本继续开发，保留 single 单文件夹模式、compare 前后对比模式、比例尺换算、尺寸提示、六项统计指标、样本 SD 误差棒及每图最多 300 秒的独立进程时限。历史 `_v32_*` / `_v33_*` / `_v35_*` 名称及兼容字段按原含义保留，运行不依赖旧版本文件。

## 本次问题与行为变化

V35 不只存在默认 0.75 圆形度阈值，还在候选搜索、形状检查和径向轮廓搜索中使用近圆假设。只降低一个参数无法保证真实椭圆被保留。V36 同时处理定位、形状审核和去重，继续把原始灰度支持的实际轮廓作为测量对象。

V35 的 slit 最终统计要求同一列的四排全部有效，局部污染可导致清晰最下排对象随整列删除。V36 将“四排形貌”作为全图结构约束，允许部分列缺失成员；真正测量的最下排对象仍必须有原图边缘。

## via：定位与真实轮廓

1. 候选池的宽松预筛不再按低圆形度或旧 2.4 长宽比删除拉长候选；候选排序不因拉长降分。图内搜索尺度继续从完整候选的等效直径估计，至少 4 个尺寸一致候选时采用其中位数，否则回退标称尺度；显式尺寸提示优先。
2. 保留原径向搜索定位以兼容弱圆孔，同时新增 `_v36_via_component_proposals`。它从候选池和图像连通轮廓中取完整候选，保留边界/面积/尺寸检查，通过 `_v32_refine_desc` 在原图灰度上追踪边缘，再做形貌检查。
3. 从有效整体轮廓的中心拟合原有二维阵列模型。候选须接近真实支持的格位，整体轮廓在阵列坐标中不能跨过相邻格位的半间距边界（绝对局部坐标小于 0.49）。模型允许内部空缺，不为缺孔生成对象。
4. 当整体轮廓能建立可靠阵列时，同格位优先使用整体轮廓。径向定位器有时把长孔两端当成多个中心，因此不再只按圆形半径邻域合并；先按格位合并，再在最终原图轮廓细化后按真实中心去重。
5. X/Y 尺寸仍是实际轮廓沿阵列坐标轴的投影跨度，乘以每图自己的 PixelSize。椭圆拟合从不替代输出轮廓，也不用于填补被污染的孔。

候选处理仍有数量上限；原图硬时限仍覆盖新增组件检查与 auto 的所有模型尝试。非常密集/低对比场景可能在时限内无可靠结果，此时继续记录超时/拒测。

## via：不惩罚正常拉长的形状审核

`_v36_via_shape_metrics` 对观测轮廓按弧长采样，拟合椭圆，把采样点转入椭圆主轴坐标并分别除以两个半轴。理想椭圆无论角度或长宽比，其归一化半径应接近 1。该坐标变换仅用于筛查不规则度，原轮廓不被替换、平滑或强行变圆。

`V36_VIA_SHAPE_LIMITS` 保存以下组合门槛，并写入 settings：

| 指标 | 定义 / 目的 | 默认门槛 |
| --- | --- | --- |
| solidity | 原轮廓面积 / 凸包面积，检测明显凹陷 | ≥ 0.85 |
| via_convexity | 弧长采样轮廓的凸包周长 / 原周长，检测锯齿和回折 | ≥ 0.88 |
| via_ellipse_residual_p95 | 椭圆归一化半径与 1 的绝对偏差 95 分位，检测多瓣和异常形态 | ≤ 0.18 |
| via_edge_roughness | 归一化半径减去环形 9 点平均后的绝对残差 95 分位 | ≤ 0.06 |
| via_minor_span_px | 可分辨的实际短轴跨度 | ≥ 4 px |

不再用原始半径 CV 或旧 1.62 长宽比作为硬门槛。新的 `via_radial_cv` 是椭圆归一化半径的 CV，仅供追溯，不与旧值直接比较。形貌检查在普通检测及各补检等级使用相同门槛，不允许补检把明显不规则轮廓放行。最终等效直径仍限制在图内搜索尺度的 0.5–2 倍，保留图像边界和邻位范围检查；这不等于将尺寸设为标称 40/60 nm。

这些门槛是本次合成验证中的默认实现，尚未针对实际批次标定；并不保证所有类型的污染都能自动分辨。例如具有完整平滑边缘、恰好位于阵列格位且尺寸相似的污渍，仅凭形状可能无法区分，应复核原图。

## 原图边缘检查不放松

沿用 `_v32_supported_contour`：对原灰度轮廓法线方向取样、估计局部内外灰度和背景平面、寻找有方向的 50% 灰度跃迁，通过闭环连续性追踪选取边缘。增强图用于定位，测量灰度始终取原图。

支持比例仍需至少 0.85；连续缺边仍受原有约 0.08 周长上限约束。仅对允许范围内的少量缺失点在真实支持端点之间线性连接，不保留无支持的尖刺，不跨大段污染补圆。面积、跨度和中心变化限制仍保留。精确形貌审核在最终原图轮廓上再次执行，因此椭圆候选放在空白原图上也不能得到有效尺寸。

## 可选旧筛选及尺寸提示

`V36DetectionOptions` 的 `via_min_circularity` 默认由 0.75 改为 0，圆形度仍保存但不默认淘汰椭圆。`via_max_size_deviation` 默认由 0.30 改为 0，避免正常拉长导致等效直径增大后再次被默认剪裁。用户显式启用非零值时仍执行对应筛选，补检不能绕过用户阈值。

同图偏差筛选显式启用后仍只计算一次同图中位数，至少 3 个通过形貌及尺寸提示的对象才执行；不跨样品或 before/after 比较。尺寸提示仍按每图 PixelSize 转为像素，最终检查宽度/直径默认 ±50%，最下排 slit 长度/trench 间隙默认 ±100%；独立容差优先于旧统一参数。主动设置的尺寸范围可能排除真实形变，应在使用说明中明确。

## slit：允许缺失，但必须有阵列和测量证据

1. 结合 V27/V30 与可选尺寸提示的定位候选，沿用 `measure_slot_v18` 的四排模型及有限补检。每个观测对象独立经过原图轮廓细化、形状和边界检查；单个对象失败不连带删除其他成员。
2. `_v36_slot_columns` 在阵列轴坐标中将实际观测中心分列，使用原有行内间距估计和有界列容差；不以第一排必须存在作为锚点。每个候选列至少有两个实际行成员；同格位保留证据更强的候选。
3. `_v36_slot_axis` 用各列两个或更多真实中心拟合方向，重新检查列分配，得到最终测量坐标轴。缺失位置不提供虚构中心参与拟合。
4. 全图必须观察到四个行级，至少两个有支持的列；至少三排各有两个对象。只有三排、整个最下排消失或只有零散底部对象时，不声称确定了第四排，不测量。
5. 新参数 `--slit-min-column-rows`（别名 `--slot-min-column-rows`）默认 2，取整数 2–4。测量列必须实际观察到第四排，且该列达到最少行数；3 更严格，4 恢复完整列要求。缺第四排时不使用第三排替代。
6. 尺寸提示只检查真实最下排对象；最终宽度/长度来自该对象的实际原图轮廓，不复制上排或邻列尺寸。没有可靠对象则不输出数值，也不填 0。

四排为全图可确认的形貌先验。V36 处理“局部对象缺失”，不承诺在整排完全遮挡、严重位移或无可靠阵列证据时恢复样品。这是避免错误编号和补造尺寸的边界。

## 标注、日志与统计一致性

- via 最终有效对象在原图上标注，新增 `via_convexity`、`via_ellipse_residual_p95`、`via_edge_roughness`、`via_shape_rule` 等审核字段。
- slit 标注绿色最下排测量对象，其余可确认的轮廓作为阵列辅助显示。缺失位置只写日志，不绘制模板轮廓。辅助轮廓可能不参与统计。
- 每个 slit 测量行新增 `slot_observed_rows`、`slot_missing_rows`、`slot_is_partial_column`、`slot_supported_column_count`；`slot_complete_column_count` 表示实际四排齐全列数，因此可为 0 而仍有有效底部测量。列号可有间隔，保留位置含义。
- 拒绝原因新增 `via_irregular_boundary`、`via_crosses_lattice_cell`、`slot_missing_or_obscured_site`、`slot_insufficient_column_support`、`slot_insufficient_array_support`。候选日志可能包含不同检测尝试，不能直接将拒绝行数当成实际污染个数。
- image_status 的 `measure_v36_slot_*` 记录阵列支持、各排数量、缺失格位、缺失底部及部分列测量数量；`measure_v36_observed_component_count` 记录 via 整体轮廓路径的数量。
- settings 保存形貌门槛、全图/单列规则、缺失处理和实际参数。single/compare 均使用相同测量策略；统计继续消费最终有效对象，按原有 n、mean、SD、SEM 和对象权重汇总。

## 输入、模式及输出兼容

主入口为 `main_v36`。CLI 继续用 `--input` 自动选 single，或 `--before` / `--after` 选 compare；也可显式指定 `--mode`。数字目录/前导零、自然排序每三张 trench/slot/via、Region 2 起始、同名 PixelSize TXT、不等数量处理规则均继承 V35。

工作簿升级为 `SEM_0830_0831_single_V36_results.xlsx` 或 `SEM_0830_0831_before_after_V36_results.xlsx`。输出需新的/空的目录，避免旧图残留。图表继续为 nm、均值 ± 样本 SD、220 dpi；缺失数据不补零。完整安装、参数及文件解释见 `README_V36.txt`。

- 缺一个 via 和一个星形污染的 20 格合成阵列保留 18 个实际椭圆，不重复测量长轴端点。校验 X/Y 尺寸而非仅对象数量；椭圆归一化不会修改输入轮廓。
- slit 三个列各缺一个不同上排成员，保留 3 个真实最下排测量；单列缺两个上排成员仍可测量，严格 4 行模式只保留完整列。缺失底部时不补造，整排消失不把上排升格。额外非阵列污渍不改变底部测量。
- 真实 CLI/独立 worker 以 PixelSize=2 处理 trench、污染 slit 和椭圆 via：30 个有效对象、18 张统计图、标注/CSV/Excel/缺失日志一致。

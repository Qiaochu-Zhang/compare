# V38：改善 slit 回退，保留 V37 via

V38 从 V37 源码建立独立版本，对照 V35 的 slit 定位、局部修复和完整列支持方式。保留单文件夹/前后对比、六项 nm 指标、每图 PixelSize、均值 ± 样本 SD、尺寸提示及单图 300 秒硬时限。

## V37 为什么会漏掉 V35 能找到的 slit

以下结论来自代码和受控合成图。用户本批 SEM 原图/TXT 暂不可用，因此不能据此判定所有实际漏检均为同一原因。

### 大窗口背景平面与单点外探产生误报

V35 在原始灰度的局部法线上追踪 50% 交点。V37 保留该追踪，另外用较大 ROI 拟合背景平面，再沿法线向外探测 `max(4,0.30×较小跨度)` px。响应超过 `max(1.5,3.5×噪声)` 的点超过 12% 时，就认为轮廓可能未覆盖完整前景。

这对上深下浅的半轮廓有效，但有三个混淆因素：

- 弯曲照明无法由单个平面解释，低频背景残差会超过固定灰度下限，轻微背景起伏被当成对象延伸。
- 单个探测点可以跨过背景间隔、落到相邻 slit 内；真实目标已完整，邻位却触发拒测。
- 模糊尾部仍有低幅响应，触发无必要的低阈值重定位；新的定位轮廓更大，局部追踪可能无法回到原来的 50% 边缘。

合成图四排中心为 y=55/145/235/325，三列，背景为倾斜平面叠加 `A*sin(x/29)*cos(y/37)`，轮廓信号经高斯模糊并加固定随机噪声。以下是整条 slit 流水线的有效最下排数量，尺寸单位为 px：

| 场景 | V35 | V37 | V38 |
| --- | --- | --- | --- |
| 弯曲背景 A=4，实际约 17×21 | 3 | 0 | 3，约 17×21 |
| 弯曲背景 A=8，实际约 17×21 | 3 | 0 | 3，约 17×21 |
| 密集三列，宽约 65，列距 80 | 3 | 0 | 3，约 65×21 |
| 模糊 sigma=3，实际约 17×21 | 3，宽约 16.3–17.6 | 3，宽约 21.8–22.0 | 3，宽约 16.3–17.6 |
| 仅一列四排完整，其他列局部缺失 | 1 | 0 | 1，约 17×21 |

额外对照：在 A=4 的图上，仅将 V37 完整性判断切换为 V38 slit 分支即可恢复 3 个对象；仅去掉补充候选、保留旧完整性判断则仍为 0。这确认该场景主要由完整性误判造成，不能把全部回退归咎于候选数量。

### 失败种子失去局部修复机会

V35 的 `_v32_valid_slot_columns` 对原图边缘验证失败的种子，利用已知行距/列距在同格位重新定位，再验证真实边缘。V36/V37 的新逐对象循环没有该分支，首个轮廓失败就跳过。局部缺失支持虽然更灵活，但弱对象或坏种子丢失了一次有用的修复机会。

### 完整列受到新增整图支持门槛限制

V35 可保留真正四排齐全、原图边缘均有效的列。V36/V37 为允许部分列引入“至少两列、至少三排重复支持”的整图约束，却同时应用于完整列。仅剩一个完整列、其他列缺失较多时，该完整列也会被删除。

此外，V37 在定位四排之前合并更多候选；合并函数会按形状质量替换重叠候选，新的非阵列候选也会参与行距/相位拟合。这是定位稳定性的风险。V38 将首轮与补检独立运行、优先保留已验证对象；不把该风险宣称为每个实际漏检的已确认原因。

## V38 slit 处理流程

1. **先处理原始候选和尺寸提示。** 沿用 V35 首轮四排定位顺序，用 `measure_slot_v18` 定位，再逐对象验证原图。保留实际观测，供阵列支持判断使用，不生成缺失轮廓。
2. **只对验证失败的种子局部修复。** 有限正行距/列距均大于 5 px 时，在原始灰度同格位调用 V30 搜索；中心位移不超过 `max(3,0.25×列距)` / `max(3,0.30×行距)`。修复候选重新通过完整性、原图追踪、形状及图像边界审核。
3. **独立补检。** V30 横向背景候选与 V37 多尺度候选另跑四排定位。首轮接受的对象优先，补检只补未占据的对象；首轮四排行级均已观测时，补充对象匹配实际行级，偏离 `max(4,0.30×行距)` 的候选记录并拒绝。部分对象成功后仍搜索其他弱对象。
4. **按 slit 局部结构复核完整性。** `_v38_slot_boundary_response` 对原始 ROI 作 sigma=0.8 平滑后，逐行计算横向形态学背景响应，核宽约为初始 X 跨度的两倍加 5（奇数，9–1025）。该响应只用于定位/审核，最终尺寸不来自响应掩膜。
5. **区分连续延伸、背景和邻位。** `_v38_slot_outer_contact` 沿法线从外侧 2 px 探到 `max(8,0.5×较小跨度)` px；该段采样均超过噪声限制才算未解释前景。背景间隔会中断连续性，较远邻位不单独触发误报，常见模糊尾部不会因一个低阈值点触发扩张。
6. **必要时保留区域重定位。** 外侧仍有连续前景或局部追踪失败时，在带背景留白的有界窗口中寻找候选；保留至少 60% 种子核心、定位面积为种子 0.65–4.5 倍、不触窗口边缘，再执行原图 50% 法线追踪。支持率至少 85%、连续缺边约 8% 上限及原形状检查保持；无法确认完整边缘时拒测。
7. **组列与支持。** 四排均有真实有效轮廓的完整列可保留。部分列仍要求全图四排行级、至少两列、至少三排重复支持；测量列须包含最下排和 `slit_min_column_rows` 个真实行级（默认 2，可选 2–4）。重复阵列不足时只保留完整列，记录部分列的拒绝原因。
8. **最终测量。** 用实际中心拟合坐标轴，只测最下排原图轮廓投影跨度，按每图 PixelSize 换算并应用用户范围。全无边缘、整排缺失、底排缺失或形状异常均不补造尺寸，不把第三排当第四排。

`V35_primary` 表示定位顺序来源，并非调用旧脚本或拼接旧版最终尺寸。V38 包独立运行，最终尺寸均通过本版原图审核。真正短的对象不会按模型拉长；弱下半部仍可通过区域重定位恢复。

## 保留 V37 的 via 与 trench

via 保留 V37 的 `_select_and_measure_vias_v19`、整体连通候选、弱对象补检、尺度/格位去重、原图细化、椭圆归一化形貌与可选尺寸筛选。默认圆形度、同图尺寸偏差筛选均关闭；显式参数仍生效。平滑拉长孔可测，明显锯齿、多瓣、大凹口仍拒绝。拟合椭圆仅用于审核，不替换测量轮廓。

共用完整性函数仅在 `pattern='slot'` 时进入新的背景/连续性分支。via 保持 V37 的背景平面和外侧探测策略。核心 via 函数、V37 候选函数及精细原图追踪经 AST 对比未改动；对弱孔阵列和旋转椭圆阵列分别运行 V37/V38，中心和尺寸逐对象一致。

trench 保留 V37 的上下条局部响应、完整包络和平台 50% 端点。宽度仍取上下平均，端点不复制全图中位值。原有约略上下区域/构图限制保留。

## 追溯字段、入口与统计

- `slit_locator_path`：`V35_primary` / `V37_supplement`；`slit_boundary_rule`：`V38_row_local_connected_outer_foreground`。
- `edge_coarse_source=V30_repair_of_unsupported_slit_candidate`：首个种子失败后，经原图重新定位并验证。
- `boundary_*`、`edge_*` 沿用完整性/原图证据字段；`boundary_relocalized` 不是准确率证明。
- image_status 的 `measure_v38_slit_primary_accepted_count`、`measure_v38_slit_supplement_added_count`、`measure_v38_slit_local_repaired_count` 为组列前的逐对象审核计数，不等于最终统计数量。
- `measure_v38_slit_primary_row_lock` 记录是否按首轮观测行级约束补检；`measure_v38_slit_complete_column_support_only` 表示重复阵列不足时仅保留完整列。
- settings 新增 `v38_slit_localization_rule` / `v38_slit_boundary_rule`，同步完整/部分列支持规则；继承的 `v37_*` / `v36_*` 字段和方法来源按实际含义保留。
- 新入口 `main_v38`、`V38DetectionOptions`、`sem_before_after_compare_0831_V38.py`；工作簿为 `SEM_0830_0831_single_V38_results.xlsx` / `SEM_0830_0831_before_after_V38_results.xlsx`。
- single / compare、自然排序、数字样品编号、Region、auto、均值 ± 样本 SD 和对象加权汇总沿用，没有有效值不填 0。

## 验证与限制

`tests/test_v38_slit_fusion.py` 直接加载 V35/V37/V38，复现上述回退并验证数量及已知跨度，另覆盖明亮极性、比例尺、尺寸提示、弱下半部、实际短对象、坏种子修复及空白原图拒绝，以及 V37/V38 via 一致性。

`tests/test_v38_edges.py`、`tests/test_v38_morphology.py`、`tests/test_v38_workflows.py` 将 V37 的 38 项场景直接用于 V38，包括真实 CLI/worker、完整轮廓、形貌、污染缺失、trench、统计、导出、auto 和超时。全仓库验证与 ZIP 校验结果见 `md/2026-10-16_V38_slit-via-fusion.md`。

本次没有真实 SEM 原图/TXT，尚不能量化实际召回率或误检率。横向背景估计依赖 slit 的现有排布；与目标相连的污染、超大模糊、比探测距离更短的弱尾部或极低信噪比仍可能难以区分。只有一个几乎无阵列参照的完整列时，上游行距/列距定位也可能失败；“允许保留完整列”不保证这种图必能建立定位。应结合原图与标注复核。Linux/Python 3.12 用于本次验证，Windows/macOS 原生运行未验证。

# V31 算法与验证说明

V31 以 V27 的几何定位为起点，借用 Yakun 的灰度边缘规则，再用 V30 恢复缺失候选。
三种方法承担不同任务，不对三个版本的尺寸简单取平均，也不以检出数量作为正确性的替代指标。

## 为什么 V30 会检出目标却量错形状

V30 在已有 slot 候选上也重新提取背景校正轮廓。已有的合理 V27 轮廓可能被不同阈值的轮廓替换。
亮度渐变、弱最下排以及局部残缺会改变二值轮廓的宽度和中心；继续扩大补点次数不能保证边缘正确。
V31 先检查 V27 候选的原图证据，仅对缺失或未通过检查的候选启用 V30 恢复。
这解释了代码中的风险来源，尚未用用户报告误测的原始图片确认其具体成因。

## 轮廓与测量

1. slot 使用 V27 四行定位及完整列约束；via 使用 V27 阵列和尺度约束；trench 使用 V27 成对定位及坐标轴。
2. slot/via 沿候选轮廓等弧长取 48–240 个点，计算局部法线。
   从原图轮廓外侧样本稳健拟合背景平面，只扣除亮度斜率，保留目标灰度跳变。
   法线剖面以 0.5 像素间隔采样，切向三个采样点平均以减少噪声。
3. 由避开模糊过渡区的内外侧灰度构建局部 50% 阈值，寻找方向正确且具有两侧灰度支持的亚像素交点。
   内侧 25% 与外侧 75% 分位值作为稳健灰度参考，减少候选偏移导致参考区混入模糊边缘的偏差。
   最低对比为 max(2.5 灰度级, 4×局部噪声估计)。边界附近搜索半径受目标宽度限制在 2–6 像素。
4. 用 Yakun 闭环动态规划挑选连续交点，不拟合椭圆/矩形。至少 85% 的采样位置需有原图支持；
   连续缺失段不得超过 max(3, floor(0.08×采样点数))，仅对这些短缺段插值。
   插值连接相邻有效交点的位置，不沿原候选上的无证据尖角插值位移，防止假尖角决定尺寸极值。
   限制面积比 0.70–1.40、X/Y 跨度比 0.75–1.25 和质心位移。
   超过几何变化限制时，仅当原轮廓至少 92% 的采样点在 0.85 像素内有边缘支持且连续缺失不超过 3 点，
   才明确标记 `V27_SUPPORTED_CONTOUR_RETAINED` 并保留该轮廓；否则拒测。
5. slot 中未通过原图检查的候选可用 V30 局部背景校正重定位，但中心不得跨到相邻单元。
   补充轮廓须重新通过同一原图检查。已通过检查的 V27 列保留；补充列按位置去重。
   四行都有效才输出最下排，重新拟合所有有效列的公共坐标轴，测量最终轮廓的实际投影跨度。
6. via 细化后再次执行原有形状和物理跨度检查，重新拟合底排坐标轴。
   椭圆相似度仅用于质量筛选，不把测量轮廓替换为拟合椭圆。
7. trench 在 V27 边缘锚点附近使用 Yakun 的带方向梯度、拓扑检查、两侧灰度 50% 交点。
   宽度仍为上下矩形宽度的算术平均，不投影到 X 轴；tip gap 仍按 V27 的 Y 轴方向投影。
   原图剖面不支持边缘或变化过大时拒绝该对。

增强图用于定位。包括 V27/V25 的零结果增强回退在内，V31 的最终边缘细化始终读取原图灰度。
定位仍可使用 V27 的百分位拉伸图；测量单独解码，8 位图保留原值，高位深图仅作浮点仿射换算，
不裁剪百分位以外的值，也不再次量化为 8 位，因此不改变局部灰度交点的几何位置。
slot/via 的背景平面校正也是从原图像素估计，并记录斜率；不以增强后的对比度充当原图证据。
V31 默认测量局部灰度 50% 边界，未移植 Yakun 的强制形状规则，也未启用独立 density 测量模式。

## 可追溯输出

保留 V27 的 CSV/Excel 表页、坐标轴、标注编号和主要尺寸定义，文件版本改为 V31。
`edge_*` 为最终边缘审核信息，`v27_*` 为该候选细化前的参考尺寸，便于检查变化。
已有 `via_good_ray_fraction`、`via_outer_dark_leak_fraction` 等历史字段描述 V27 定位阶段，
最终轮廓的支持情况以 `edge_support_fraction` 等 V31 字段为准。
图像级状态、错误和时限写入状态表；每完成或跳过一张图片刷新状态/错误 CSV。

## 5 分钟上限

每张图片在独立 Python 子进程中运行。父进程使用单调时钟监控同一个不超过 300 秒的预算，
其中包含所有补检、via 自动模型尝试与标注生成。超时先 terminate，必要时 kill，继续下一张。
子进程先写临时目录，仅成功完成后发布结果，超时不把未完成标注作为有效输出。
终止清理有至多约 4 秒额外等待；总表和整批汇总绘图不属于单张图片的识别预算。
所有 via 自动模型尝试共用一个预算，选定结果直接复用；不重复测量获胜模型。

## 验证及限制

`tests/test_v31.py` 覆盖解析灰度图的椭圆/圆角矩形及旋转轮廓、背景渐变、低对比、
弱最下排、最下排位移、亮/暗极性、原图审核、缺行拒测、via 阵列、trench 测量和标注。
同时验证真实子进程被终止、未完成结果未发布、超时后继续、两个 via 模型共用预算。

数值容差：解析椭圆/圆角矩形及 via 的已知 50% 灰度边界跨度误差不超过 0.7 px；
带量化噪声和背景渐变的 slot 补检测试尺寸误差不超过 0.8 nm，含实际二值分割/候选池的测试不超过 1.0 nm（PixelSize=0.8 nm/px）；
trench 宽度和 tip gap 误差不超过 0.7 px。这里是测试断言容差，不是实际 SEM 精度承诺。

仓库没有用户报告误测的原始 SEM 图片与对应标尺文件，因此真实图上的准确率、
拒测率以及参数适配仍需以该批图片复核；不能仅凭合成测试证明所有真实形状都能正确识别。
